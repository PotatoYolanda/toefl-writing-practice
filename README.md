# 托福写作练习

托福写作练习网页：每天写一篇托福邮件或学术讨论帖，四周重点递进，含批改复习和作文库。

## 使用

直接用浏览器打开 `index.html` 即可，不需要安装任何东西。学习记录保存在浏览器本地（localStorage）。

> 这个网页最初发布在 claude.ai 上。在 claude.ai 登录状态下打开时，学习记录可以在不同设备间同步；从这里打开时，记录只保存在当前浏览器里。
